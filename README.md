## 🎯 ¿Qué es Acá Falta la Muni y por qué nace?

En la comuna de **Osorno** (Región de Los Lagos, Chile), con una extensión geográfica de **951 km²** y más de **170 000 habitantes**, las demandas por infraestructura básica frecuentemente se extravían en la burocracia edilicia:
- Baches históricos que destruyen trenes delanteros, rompen neumáticos y causan accidentes en Rahue, Ovejería, Francke, Kolbe o el Centro.
- Luminarias apagadas durante meses que convierten esquinas y pasajes en focos de delincuencia e inseguridad vecinal.
- Microbasurales clandestinos en riberas de ríos y caminos rurales sin retiro oportuno de desechos.
- Rezago profundo en sectores campesinos y localidades rurales —tales como **Cancura, Pichil, Curaco, Tacamó, Forrahue, Trumao, Las Quemas y Polloico**— que a menudo quedan invisibilizados frente al radio urbano céntrico.

**«Acá Falta la Muni — Osorno»** nace como una herramienta comunitaria independiente, ciudadana, no partidista y sin fines de lucro para:
1. **Visibilizar la inacción:** Cuantificar y exponer públicamente los días corridos acumulados sin reparación oficial por parte de la Municipalidad.
2. **Empoderar a las Juntas de Vecinos:** Proporcionar oficios jurídicos automáticos basados en la legislación chilena para exigir respuestas a la autoridad edilicia o denunciar el abandono ante la **Contraloría General de la República (CGR)**.
3. **Fomentar la solidaridad vecinal:** Permitir comentarios comunitarios en tiempo real y apoyos solidarios (+1) para respaldar colectivamente las problemáticas barriales más graves.
4. **Erradicar la disparidad territorial:** Monitorear con datos abiertos e inmutables si la inversión y las cuadrillas municipales atienden con equidad a todos los cuadrantes comunales.

## 🚀 Funcionalidades Principales

### 🗺️ 1. Mapa Comunal Interactivo en Tiempo Real
- Cobertura georreferenciada integral de los **951 km²** de Osorno mediante cartografía libre de **OpenStreetMap** con capas de alto contraste.
- Mapa térmico (*heatmap*) interactivo para localizar concentraciones críticas de baches y abandono vial.
- Categorías organizadas: Calles y Baches, Luminarias, Microbasurales, Áreas Verdes, Señalética y Aguas Lluvias.

### ☁️ 2. Base de Datos Central en la Nube (Cloud Firestore en Producción)
- Todas las denuncias, estados y apoyos se sincronizan al instante en una base de datos centralizada de alta disponibilidad.
- Cualquier reporte ingresado desde un teléfono móvil se refleja inmediatamente en el mapa de todos los vecinos y en la versión web a 0 ms.

### 💬 3. Muro Vecinal de Comentarios en Vivo y Apoyo Solidario (+1)
- Cada denuncia cuenta con su propio muro de deliberación comunitaria en tiempo real.
- Los vecinos del sector pueden aportar detalles complementarios («el hoyo se tapó con tierra y volvió a ceder»), testimoniar accidentes o respaldar con un toque (+1) la urgencia de la reparación.
- Registro cronológico transparente y abierto para fiscalización ciudadana.

### 🛡️ 4. Captcha Aritmético Anti-Spam (Suma Escolar Simple)
- Para prevenir vandalismo digital y *spam* automatizado sin perjudicar la accesibilidad de adultos mayores o dirigentes sociales, la plataforma incorpora un desafío aritmético escolar elemental (por ejemplo: `¿Cuánto es 4 + 7?`).
- Sin códigos distorsionados incomprensibles ni recolección de datos por parte de terceros (sin reCAPTCHA comercial invasivo).

### ⏱️ 5. Contador Público de Días de Inacción Edilicia
- Cada registro almacena la fecha y hora de creación.
- La plataforma calcula automáticamente los días corridos transcurridos:
  - 🟢 **Reciente:** Menos de 7 días.
  - 🟡 **En espera prolongada:** 7 a 30 días.
  - 🔴 **Abandono municipal:** Más de 30 días sin solución formal.

### ⚖️ 6. Generador Automatizado de Oficios Legales Imprimibles (PDF)
Cualquier vecina, dirigente de Junta de Vecinos (JJ.VV.) o concejal puede convertir un reclamo en un oficio formal listo para imprimir o enviar con respaldo normativo chileno:
- **Ley N° 18.695 (Orgánica Constitucional de Municipalidades):** Arts. 1°, 3° letra f) y 5° letras c) y d), que consagran la responsabilidad municipal privativa sobre el mantenimiento de bienes nacionales de uso público y el estado de las vías comunales.
- **Ley N° 19.880 (Bases de los Procedimientos Administrativos):** Arts. 7°, 8° y 14, que establecen los principios de celeridad, conclusivo y el plazo perentorio legal máximo de 30 días para dictar resolución formal.
- **Ley N° 18.290 de Tránsito:** Art. 99, que determina la responsabilidad civil directa e indemnizatoria de la municipalidad por daños corporales o materiales a vehículos originados por pavimentos en mal estado o señalización ausente.
- **Destinatarios oficiales:** Ilustre Municipalidad de Osorno y Contraloría Regional de Los Lagos (CGR) — Unidad de Control y Fiscalización.

### 📶 7. PWA Universal y Resiliencia Rural Sin Conexión
- Instalación como **Progressive Web App (PWA)** en Android, iPhone, Windows, macOS o Linux con 1 toque.
- Almacenamiento local preventivo (*Service Worker*) para consultar y registrar reportes aun en zonas campesinas de la cordillera de la Costa o riberas fluviales donde la señal 4G/5G oscila.


## 💻 Desarrollo y Compilación Local

### Requisitos Previos
- **Node.js:** Versión 22.0.0 o superior (LTS recomendada).
- **npm:** Versión 10 o superior.

### 1. Clonar el Repositorio
```bash
git clone https://github.com/elpabloultron/aca-falta-la-muni-osorno.git
cd aca-falta-la-muni-osorno
```

### 2. Instalar Dependencias
```bash
npm install
```

### 3. Servidor Local de Desarrollo
```bash
npm run dev
```
Abre en tu navegador web: `http://localhost:3000`

### 4. Pruebas Automatizadas de Lógica, Moderación y Persistencia
```bash
npm test
```

### 5. Compilación para Producción (Export Estático)
```bash
# Para Firebase Hosting o servidor HTTP estándar:
npm run build

# Para GitHub Pages (con prefijo de ruta /aca-falta-la-muni-osorno):
GITHUB_PAGES=true npm run build
```

## 📲 Compilación del Paquete Android Nativo (APK)

El proyecto nativo de Android se encuentra en el directorio `android/`:

```bash
# 1. Compilar export estático de Next.js
npm run build

# 2. Sincronizar activos hacia el proyecto Android
npx cap sync android

# 3. Compilar APK con Gradle
cd android
./gradlew assembleDebug
```
El archivo ejecutable se ubica en: `android/app/build/outputs/apk/debug/app-debug.apk`.
