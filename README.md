## 🎯 ¿Qué es Acá Falta la Muni y por qué nace?

En la comuna de **Osorno** (Región de Los Lagos, Chile), con una superficie de **951 km²** y más de 170 000 habitantes, los problemas de infraestructura comunitaria suelen quedar atrapados en la burocracia:
- Baches históricos que rompen neumáticos y causan accidentes en Rahue, Ovejería, Francke o el Centro.
- Luminarias quemadas que fomentan la delincuencia e inseguridad en los barrios.
- Microbasurales clandestinos que proliferan en riberas de ríos y caminos vecinales.
- Aislamiento y retrasos extremos en sectores campesinos y rurales como **Cancura, Pichil, Curaco, Tacamó, Forrahue, Trumao, Las Quemas y Polloico**.

**«Acá Falta la Muni — Osorno»** nace como una herramienta ciudadana y cívica no partidista, 100 % comunitaria y sin fines de lucro, para:
1. **Visibilizar la inacción:** Calcular y exhibir públicamente cuántos días lleva un problema sin respuesta oficial de la Municipalidad.
2. **Empoderar a las Juntas de Vecinos:** Generar oficios jurídicos formales con base en la ley chilena para exigir respuestas a la alcaldía o denunciar el abandono ante la **Contraloría General de la República (CGR)**.
3. **Erradicar la disparidad territorial:** Monitorear con datos duros si los recursos y cuadrillas municipales se concentran en el sector oriente/centro en desmedro de los sectores vulnerables y rurales.

## 🚀 Características Principales

### 🗺️ 1. Mapa Comunal Interactivo en Tiempo Real
- Cobertura georreferenciada de los 951 km² comunales mediante cartografía abierta de **OpenStreetMap** y capas visuales oscuras de alto contraste.
- Marcadores de calor (*heatmap*) para identificar zonas críticas de baches y abandono vial.
- Clasificación visual por categorías: Calles/Baches, Luminarias, Microbasurales, Áreas Verdes, Señalética y Aguas Lluvias.

### ⏱️ 2. Contador Público de Días de Inacción
- Cada denuncia registra la fecha exacta de ingreso.
- El sistema calcula y exhibe públicamente los días corridos acumulados sin reparación:
  - 🟢 **Reciente:** Menos de 7 días.
  - 🟡 **En espera prolongada:** 7 a 30 días.
  - 🔴 **Abandono municipal:** Más de 30 días sin solución.

### ⚖️ 3. Generador Automatizado de Oficios Legales Imprimibles (PDF)
Cualquier vecina, dirigente de Junta de Vecinos (JJ.VV.) o concejal puede transformar un reclamo en un oficio formal descargable e imprimible con respaldo normativo chileno:
- **Ley N° 18.695 (Orgánica Constitucional de Municipalidades):** Arts. 1°, 3° letra f) y 5° letras c) y d), que consagran la responsabilidad municipal privativa sobre el estado de las vías y bienes nacionales de uso público.
- **Ley N° 19.880 (Bases de los Procedimientos Administrativos):** Arts. 7°, 8° y 14, que fijan los principios de celeridad, conclusivo y el plazo perentorio legal máximo de respuesta de 30 días.
- **Ley N° 18.290 de Tránsito:** Art. 99, que establece la responsabilidad civil e indemnizatoria de la municipalidad por daños ocasionados a vehículos o personas debido al mal estado de las vías o señalización deficiente.
- **Oficio dirigido a:** Ilustre Municipalidad de Osorno y a la Contraloría Regional de Los Lagos (CGR) — Unidad de Control de Legalidad.

### 🛡️ 4. Blindaje Anti-Vandalismo y Moderación Comunitaria
- **100 % Anónimo:** No se exige RUT ni ClaveÚnica para ingresar un reporte, eliminando cualquier barrera al ejercicio cívico.
- **Protección contra spam:** Límite preventivo de peticiones por dispositivo.
- **Moderación comunitaria:** Si un reporte falso o inapropiado acumula **3 marcas de denuncia vecinal independientes**, el sistema lo oculta automáticamente de forma preventiva en el mapa y en las estadísticas.

### 📶 5. Soporte PWA y Resiliencia Rural Offline
- La plataforma funciona como una **Progressive Web App (PWA)** instalable en Android, iPhone y PC en 2 toques sin descargas pesadas.
- Cacheo de teselas de OpenStreetMap mediante *Service Worker*, permitiendo consultar el mapa en caminos rurales de Osorno donde la señal 4G/5G se interrumpe.


## 💻 Desarrollo y Compilación Local

### Requisitos
- **Node.js:** Versión 22.0.0 o superior (LTS recomendada).
- **npm:** Versión 10 o superior.

### 1. Clonar el Repositorio
```bash
git clone https://github.com/elpabloultron/aca-falta-la-muni-osorno.git
cd aca-falta-la-muni-osorno
```

### 2. Instalar Dependencias
```bash
npm install
```

### 3. Ejecutar en Servidor Local de Desarrollo
```bash
npm run dev
```
Abre en tu navegador: `http://localhost:3000`

### 4. Ejecutar Pruebas Automatizadas de Lógica y Persistencia
```bash
npm test
```

### 5. Compilar para Producción (Export Estático)
```bash
# Para Firebase Hosting o despliegue estándar:
npm run build

# Para GitHub Pages (con basePath /aca-falta-la-muni-osorno):
GITHUB_PAGES=true npm run build
```

## 📲 Compilación de la Aplicación Android Nativa

El proyecto nativo Android se encuentra configurado en la carpeta `android/` con Capacitor 8 y Gradle:

```bash
# 1. Compilar export estático de Next.js
npm run build

# 2. Sincronizar activos web con el proyecto Android
npx cap sync android

# 3. Compilar APK con Gradle
cd android
./gradlew assembleDebug
```
El archivo APK generado quedará en: `android/app/build/outputs/apk/debug/app-debug.apk`.
